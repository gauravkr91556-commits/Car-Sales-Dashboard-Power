# Car-Sales-Dashboard-Power
# 🚗 Car Sales Dashboard – Power BI

##  1 Project Overview

****This project is an **interactive Car Sales Dashboard developed in Microsoft Power BI**. The dashboard helps car dealerships monitor and analyse their sales performance through important KPIs, interactive charts, and detailed sales information.***

The main goal of this project is to convert raw car sales data into meaningful insights that can help understand sales trends, pricing, customer preferences, and regional performance.

## 2 Project Objective

The objective is to create a dynamic dashboard that provides a clear view of car sales performance and helps users:

* Monitor total sales performance
* Compare current sales with previous years
* Analyse average car prices
* Track the number of cars sold
* Understand weekly sales trends
* Analyse sales by body style and colour
* Compare sales across dealer regions
* View company-wise sales performance
* Explore detailed information for individual car sales

## 3 Key KPIs

### Sales Overview

* **YTD Total Sales**
* **MTD Total Sales**
* **YOY Sales Growth**
* **YTD Sales vs Previous Year YTD (PTYD)**

### Average Price Analysis

* **YTD Average Price**
* **MTD Average Price**
* **YOY Average Price Growth**
* **YTD Average Price vs PTYD Average Price**

### Cars Sold

* **YTD Cars Sold**
* **MTD Cars Sold**
* **YOY Growth in Cars Sold**
* **YTD Cars Sold vs PTYD Cars Sold**
## 4 Project Outcome

The project demonstrates how Power BI, Power Query, DAX, and data visualization can be used to transform car sales data into an interactive business dashboard and support data-driven decision-making.
